## ⚡ Overview

A cyberpunk / terminal-inspired personal engineering portfolio built for high-performance interactivity and telemetry showcase. Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Motion**, featuring custom ambient particle grids, real-time live system clocks, and structured case studies of peer-reviewed research and AI systems.

### 🌟 Key Highlights

- **Live Status & Telemetry Bar:** Dynamic UTC/IST real-time telemetry indicators, uptime, and system status counters.
- **Interactive Project Deep Dives:** Detailed breakdowns of machine learning systems, model architectures, metrics, and peer-reviewed DOI publications.
- **Technical Arsenal & Skills Radar:** Categorized matrix covering Programming, Data Science, Machine Learning, Deep Learning/CV, Web Systems, and Databases.
- **Publications & Research Registry:** Highlighted citations from international journals (IJARSCT) and conferences (ETRCEE).
- **Responsive Terminal Aesthetics:** Cyber-grid visual backgrounds, custom glowing borders, scanline overlays, and mobile-optimized layouts.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [Git](https://git-scm.com/)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/parasmulwande-sketch/paras-mulwande-portfolio.git
   cd paras-mulwande-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
